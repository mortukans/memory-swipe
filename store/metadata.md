**App Review notes**:
```
Memory Swipe is a fully offline photo-library tidying app. It requests Photos access (full or limited) and reads only the user's own photos and videos. It stores keep/remove decisions in a local SQLite database. Nothing is uploaded; there are no accounts, servers or analytics.

To test: grant photo access on the welcome screen → tap "Surprise me" → swipe right (keep) or left (set aside) → open the Review tab → "Delete N items" shows the standard iOS deletion confirmation. Deletion uses PHAssetChangeRequest.deleteAssets and only runs after the user confirms the system dialog. Items go to Recently Deleted.

The app has no sign-in, so no demo account is needed.
```
